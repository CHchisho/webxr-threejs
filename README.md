# Snowman (Three.js)

A small Vite + Three.js scene: a snowman made from basic shapes.

## What is in the scene

- Three geometry types: spheres (body), a cone (carrot nose), cylinders (hat)
- Materials that react to light: Phong, Lambert, and Standard
- Ambient, directional, and point lights
- An axis helper and OrbitControls for the camera

## Scripts

```bash
npm install
npm run dev
npm run build
```
